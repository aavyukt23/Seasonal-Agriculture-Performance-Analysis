# Seasonal Agriculture Performance Analysis

## Project Overview

This project analyzes agricultural performance across Kharif, Rabi, and Zaid seasons.

The analysis focuses on seasonal variations in crop yield, environmental conditions, resource usage, and economic performance.

## Dataset

The dataset contains 4,000 agricultural records and 28 attributes covering:

- Crop and season
- Geographical information
- Environmental conditions
- Resource usage
- Yield and production
- Market price
- Cost, revenue and profit
- Water usage
- Disease and pest risk

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Analysis Performed

- Data cleaning
- Exploratory data analysis
- Seasonal comparison
- Environmental analysis
- Resource usage analysis
- Economic analysis
- Crop-season comparison
- State-season comparison
- Correlation analysis
- One-way ANOVA

## Key Finding

Kharif showed the highest observed average yield and profit, while Zaid showed lower average yield and negative average profit. However, ANOVA did not provide sufficient statistical evidence that mean yield differs significantly across seasons.
